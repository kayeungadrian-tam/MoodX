# MoodX two-minute video delivery

This folder is the permanent project copy of the 16:9 MoodX concept-video
delivery. The `dist/video/` directory remains an ignored local build output;
these files are retained in the workspace for review and publication handoff.

## Files

- `moodx-2min-16x9.mp4` — 119.9-second H.264 video at 1920 × 1080 and 30 fps,
  with AAC preview narration and embedded English captions.
- `moodx-2min-16x9.en.srt` — separate English caption upload file.
- `youtube-thumbnail.jpg` — 1280 × 720 thumbnail.
- `moodx-2min-16x9-contact-sheet.jpg` — six-frame visual review sheet.
