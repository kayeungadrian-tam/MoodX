# MoodX Documentation

This directory is the centralized home for MoodX project documentation.

## Canonical records

- [Architecture Decision Record](ADR.md) — append-only architectural and
  governance decisions.
- [Meeting memo](MEETING_MEMO.md) — chronological record of every working
  session.
- [Product roadmap](ROADMAP.md) — centralized delivery, validation, and
  deferral priorities.
- [Living pitch deck](pitch-deck/index.html) — the centralized HTML/CSS product
  presentation.
- [Research records](research/) — dated, source-grounded research briefs.
- [Product problem definition](product/PROBLEM_DEFINITION.md) — current problem,
  users, hypotheses, guardrails, and validation questions.
- [Customer journey](product/CUSTOMER_JOURNEY.md) — implemented facilitator
  journey, intended participation loop, product gaps, and next test slice.
- [Teams meeting energy console](product/TEAMS_MEETING_ENERGY_CONCEPT.md) —
  facilitator experience, soundboard concept, delivery options, and guardrails.
- [Technical documentation](technical/README.md) — system context, system
  overview, native architecture, data flow, Mermaid diagrams, and traceable
  requirements.
- [macOS beta distribution](technical/BETA_DISTRIBUTION.md) — current release
  readiness, recommended notarized-beta path, and TestFlight trade-offs.
- [Native macOS mixer setup](../macos/MoodXMixer/README.md) — build instructions,
  BlackHole routing, controls, and current limitations.
- [Browser mixer prototype](../mixer/README.md) — retained interaction prototype
  and local fallback.
