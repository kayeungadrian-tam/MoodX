## MoodX Working Contract

These rules apply to every session and every contributor working in this
repository:

1. Document all meaningful work. Update the relevant documentation in the same
   change as the code, configuration, design, or product decision.
2. Record every architectural decision in [`docs/ADR.md`](docs/ADR.md). Never rewrite
   accepted history; add a new decision that supersedes an older one.
3. Add a dated entry to [`docs/MEETING_MEMO.md`](docs/MEETING_MEMO.md) for every working
   session, including goals, discussion, decisions, work completed, and next
   steps.
4. Keep the centralized HTML presentation in [`docs/pitch-deck/`](docs/pitch-deck/)
   aligned with the current product direction, architecture, evidence, and ask.
5. Do not invent missing facts. Mark unknown content as `TBD` and resolve it in
   a later session.
6. Documentation is part of the definition of done. A task is incomplete until
   the ADR, meeting memo, pitch deck, README, and any task-specific docs that it
   affects have been reviewed and updated where relevant.

When a document does not need a content change, note that it was reviewed in
the current session entry in `docs/MEETING_MEMO.md`.
