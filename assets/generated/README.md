# Generated MoodX Assets

This directory is the canonical home for AI-generated project imagery.

Every generated image, regardless of provider or tool, must have an adjacent
`<image-name>.<extension>.json` sidecar containing its exact prompt, provider,
model when exposed, requested format, generation time, and SHA-256 digest. Use
`TBD` instead of guessing metadata that a provider does not expose. Keep
exploratory outputs clearly named and record selected final assets in the
relevant session memo.

Public uses must visibly disclose that selected visuals were generated with AI
and reviewed by the MoodX team. Label concept art and product mockups explicitly
when viewers might mistake them for documentary evidence or implemented UI.
Preserve the original output and sidecar even when a derived asset is exported.

Do not place API credentials, real personal data, or unlicensed reference
material here.
